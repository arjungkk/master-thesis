	\chapter{Methodology \& Computational Framework}
	\label{Chapter::Methodology}
	
	This chapter presents the methodology followed to simulate creep behaviour, generate a synthetic dataset, represent creep curves efficiently, develop machine learning surrogate models, and implement an active learning framework for data-efficient model improvement. The approach integrates numerical simulation with data-driven learning techniques to model complex creep behaviour efficiently.
	
	\section{Overview of Workflow}
	\label{Section::Workflow}
	
	Figure~\ref{fig:workflow} illustrates the complete hybrid modelling pipeline. It includes:
	
	\begin{enumerate}
		\item Sampling and selection of simulation parameters (Latin Hypercube + log-scaling).
		\item Creep curve generation using the \texttt{Lagamine} finite element solver.
		\item Preprocessing and normalization of output strain-time data.
		\item Curve representation using different models (like PCA, Kernel PCA,  $\theta$-Projection Model, etc.).
		\item Supervised regression model training (Random Forest, Gradient Boosting, etc.).
		\item Prediction of creep behaviour from material parameters and loading inputs.
		\item Iterative improvement using active learning with feasibility filtering.
	\end{enumerate}
	
	\begin{figure}[H]
		\centering
		\includegraphics[width=1.2\textwidth]{figures/workflow_diagram.png}
		\caption{Overall workflow for the hybrid framework combining FEM simulation, curve representation, supervised regression, and active learning.}
		\label{fig:workflow}
	\end{figure}
	
	\section{Synthetic Data Generation Setup}
	\label{Section::Synthetic_data_generation}
	
	\subsection{Simulation Environment and Material Model}
	
	All simulations are performed using the non-linear finite element solver \texttt{Lagamine}, developed at the University of Liège for non-linear, large-deformation thermomechanical analysis \cite{morch2022creep}. It supports large-strain, time-dependent, and thermomechanical creep analysis. The underlying constitutive model is based on Morch's internal variable formulation \cite{morch2022creep} and models all three creep stages.
	
	The material simulated is \textbf{30CrMoNiV5-11}, a creep-resistant alloy steel widely used in power and aerospace applications. It is part of the materials portfolio studied in the AID4GREENEST project \cite{aid4greenest}.

	\subsection{Simulation Parameters and Design Space}
	
	
	The simulations covered a high-dimensional parameter space representative of physically relevant material and loading conditions. Sampling was done using \textbf{Latin Hypercube Sampling (LHS)} to ensure uniform coverage of the design space. 
	
	However, in accordance with \textit{Morand et al.} \cite{morand2022efficient}, the hardening coefficient \( b \) was sampled on a \textbf{logarithmic scale}. This decision was based on the observation that small changes in \( b \) significantly impact the shape and slope of the creep curve, especially in the early stages. Logarithmic sampling ensured better representation of the steep regions in the creep response space.
	
	The final sampled parameter space is summarized in Table~\ref{tab:param_ranges}.

	\section{Creep Curve Representation}
	\label{Section::Curve_Features}
	
	Each finite element simulation outputs a creep strain–time curve data along with the material model parameters. To enable machine learning, these curves are transformed into low-dimensional representations using a combination of mathematical fitting and data-driven feature extraction techniques. The approaches implemented in this thesis are grouped into the following categories:
	
	\subsection{A. Mathematical Models}
	
	\subsubsection{1. $\theta$-Projection Model}
	
	The $\theta$-projection model \cite{brown2002extrapolation} is a semi-empirical equation used to represent creep strain evolution with four scalar parameters:
	
	\begin{equation}
	\varepsilon(t) = \theta_1 \left(1 - e^{-\theta_2 t}\right) + \theta_3 \left(e^{\theta_4 t} - 1\right)
	\label{eq:theta_projection}
	\end{equation}
	
	Where:
	\begin{itemize}
		\item $\theta_1$ and $\theta_3$: Strain magnitudes,
		\item $\theta_2$ and $\theta_4$: Curvature (rate) parameters for primary and tertiary stages
	\end{itemize}
	
	This model is widely used for engineering creep prediction and provides a compact description of the strain evolution using physically interpretable terms.
	
	\subsubsection{2. Three-Stages of Creep Model}
	
	The three-stages of creep model introduced by Dacol and Caetano~\cite{dacol2022modelling} describes the creep strain evolution using a unified analytical expression that captures all three classical stages of creep. The model is given by:
	
	\begin{equation}
	\varepsilon_e(t) = k \cdot e^{\alpha \cdot t^{\beta}}
	\label{eq:three_stage_creep_equation}
	\end{equation}
	
	where:
	\begin{itemize}
		\item \( \varepsilon_e(t) \) is the creep strain at time \( t \),
		\item \( k \) is a constant for a given temperature and load,
		\item \( \alpha \) and \( \beta \) are material-dependent fitting parameters, subject to \( \alpha > 0 \), \( \beta < 1 \), and \( \alpha \ll \beta \).
	\end{itemize}
	
	This model enables a continuous representation of the primary, secondary, and tertiary creep stages in a compact exponential-power law formulation, and is particularly suitable for long-term extrapolation of creep data.

	
	\subsection{B. Data-Driven Representations}
	
	Prior to performing dimensionality reduction, the synthetic dataset are partitioned into training and test sets, following an 80\%–20\% ratio. This allows unbiased performance assessment of subsequent machine learning models.
	
	The creep strain–time data poses specific challenges due to variations in rupture times. In particular, early rupture curves introduces missing values or infinite entries, necessitating specialized preprocessing to ensure stable application of PCA and kernel PCA.
	
	Three strategies are implemented to handle early rupture scenarios:
	
	\begin{enumerate}
		\item \textbf{Zero padding:} Missing data points after rupture are replaced with zeros, effectively truncating the creep curve and clearly marking the rupture event.
		
		\item \textbf{Max strain padding:} After rupture, the creep strain values are held constant at the last observed strain, ensuring smooth continuity and preventing abrupt changes.
		
		\item \textbf{Normalization by rupture time:} Each creep curve is normalized based on its rupture time, converting absolute time scales to a relative scale (from 0 to 1). This approach aligns the deformation trajectories across samples, effectively mitigating variations caused by early ruptures.
	\end{enumerate}
	
	These preprocessing methods will significantly improve data consistency, eliminating NaNs and infinite values, thereby enhancing the robustness of dimensionality reduction processes. 
	
	\subsubsection{1. Principal Component Analysis (PCA)}
	
	PCA is a widely used linear dimensionality reduction technique that transforms high-dimensional data into a set of orthogonal components \cite{bishop2006pattern}. The transformation preserves directions of maximum variance, allowing for compact and informative representations of creep curves. In this work, PCA is applied individually to datasets prepared with each of the three preprocessing strategies mentioned above. An analysis is made on how many principal components are able to capture over 95\% of the variance, enabling substantial dimensionality reduction without significant loss of information.
	
	Figure~\ref{fig:pca} illustrates the workflow of how PCA is used. The training set of creep curves obtained from the synthetic data are transformed to lower dimensional space with PCA and the model is saved. Then an inverse transformation of the model is applied to reconstruct the creep curves from the test set.
		
	\begin{figure}[H]
		\centering
		\includegraphics[width=0.9\textwidth]{figures/pca.png}
		\caption{Principal Component Analysis(PCA) Workflow.}
		\label{fig:pca}
	\end{figure}
	
	\subsubsection{2. Kernel Principal Component Analysis (Kernel PCA)}
	
	Kernel PCA extends PCA by performing non-linear transformations of data into a higher-dimensional feature space using kernel functions, enabling better representation of non-linear deformation trends across creep curves. Two kernels are explored in this study:
	
	\begin{itemize}
		\item \textbf{Polynomial kernel (degree 6)}, capturing polynomially non-linear features.
		\item \textbf{Radial Basis Function (RBF) kernel} with hyper-parameter $\gamma = 0.01$, suitable for more complex, localized non-linear patterns.
	\end{itemize}
	
	\begin{figure}[H]
		\centering
		\includegraphics[width=0.9\textwidth]{figures/kpca.png}
		\caption{Kernel Principal Component Analysis(KPCA) Workflow.}
		\label{fig:kpca}
	\end{figure}
	
	Figure~\ref{fig:kpca} illustrates the workflow of how KPCA is used. The training set of creep curves obtained from the synthetic data are transformed to lower dimensional space with KPCA(using different kernels) and the model is saved. Then an inverse transformation of the model is applied to reconstruct the creep curves from the test set.
	
	Kernel PCA proves to be particularly useful in distinguishing curves with non-monotonic behaviour or abrupt transitions between creep stages, which linear PCA could not represent adequately.
		
	
	\section{Supervised Learning}
	\label{Section::Supervised_Learning}
	
	Supervised learning models are used to approximate the relationships between simulation input parameters and the output representations of creep behaviour. These models serve as predictive substitutes for high-fidelity simulations, enabling both forward modelling (e.g., curve prediction) and inverse analysis (e.g., parameter identification). The core advantage lies in their ability to provide fast predictions once trained, significantly reducing computational cost compared to full-scale finite element simulations.
	
	Several regression-based algorithms are implemented using the \texttt{scikit-learn} framework \cite{pedregosa2011scikit}. These models are trained to map from the 8-dimensional input space (see Table~\ref{tab:param_ranges}) to $\theta$-parameters. Figure~\ref{fig:supervised_learning} illustrates the workflow of how Supervised Learning was used. 
	
	\begin{enumerate}
		\item Training set of creep curves obtained from the synthetic data are transformed to theta space with $\theta$-projection mapping.
		\item Transformed data is trained on a Regression model.
		\item Predicts material model parameters for the test set.
		\item Generates creep curves with the obtained parameters using \texttt{Lagamine} solver.		
	\end{enumerate}
	
	\begin{figure}[H]
		\centering
		\includegraphics[width=0.9\textwidth]{figures/supervised_learning.png}
		\caption{Supervised Learning Models Workflow.}
		\label{fig:supervised_learning}
	\end{figure}
	
	\subsection*{1. Random Forest Regressor (RFR)}
	
	The Random Forest Regressor is an ensemble method based on decision trees, where predictions are made by averaging the output of multiple trees trained on bootstrapped samples of the dataset \cite{breiman2001random}. It naturally captures non-linear relationships and feature interactions, and is robust to outliers and over-fitting. In this work, RFR is used as a baseline model due to its interpretability and fast training time.
	
	\subsection*{2. Gradient Boosting Regressor (GBR)}
	
	Gradient Boosting Regressor builds an additive model in a forward, stage-wise fashion by minimizing a specified loss function via gradient descent \cite{friedman2001greedy}. It is particularly effective for structured data with complex patterns.
	
	\subsection*{3. Stacking Regressor}
	
	Stacking, or stacked generalization, is a meta-learning technique where multiple base regressors are combined using a higher-level learner \cite{wolpert1992stacked}. In this study, base models like RFR and GBR are combined and a linear regression model is used as the meta-learner. This approach leveraged the complementary strengths of each algorithm and helped improve generalization.
	
	\subsection*{4. Voting Regressor}
	
	The Voting Regressor combines multiple base regressors by averaging their predictions (soft voting), which often improves robustness and reduces variance \cite{zhang2012ensemble}. 
	
	\subsection*{Training and Validation Strategy}
	
	All models are trained on the 80\% training split of the data using 5-fold cross-validation for hyperparameter tuning. The final performance is assessed on the held-out 20\% test set. Grid search is employed for key hyperparameters such as the number of estimators, tree depth, and learning rate.
	
	These supervised regressors provides an effective solution for capturing the complex input–output relationships inherent in time-dependent, non-linear creep simulations.

	
	\section{Active Learning}
	\label{Section::Active_Learning}
	
	An active learning loop is implemented to reduce the need for dense sampling:
	
	\begin{itemize}
		\item \textbf{Feasibility filter}: An Isolation Forest model is trained to identify whether a set of input parameters would result in valid simulation output, helping avoid computationally wasted queries.
		\item \textbf{Label space}: Theta values are used for diversity-based selection.
		\item \textbf{Query strategy}: Select points farthest from current label distribution.
		\item \textbf{Feedback loop}: Each batch updates the training data and retrain the model \cite{settles2010active}.
	\end{itemize}

	\section{Evaluation Metrics}
	\label{Section::Evaluation}
	
	To assess model performance comprehensively, several metrics are evaluated:
	
	\begin{itemize}
		\item \textbf{RMSE on Reconstruction}: Measures error in predicted creep curves, reflecting the ability to reconstruct the original curve shape.
		\item \textbf{Minimum Creep Rate Error}: Evaluate accuracy in capturing the slope of the secondary stage, which is critical for design applications.
		\item \textbf{Rupture Time Prediction Error}: The difference between predicted and actual rupture times, useful for lifecycle assessments.
		\item \textbf{Visual Similarity}: Overlay plots of predicted vs. true creep curves are generated to validate qualitative matching.
		\item \textbf{Inverse Accuracy}: Measure the accuracy of recovering simulation input parameters from curve features using inverse modelling.
	\end{itemize}
	
	Together, these metrics ensure both the quantitative accuracy and qualitative validity of the developed models.
