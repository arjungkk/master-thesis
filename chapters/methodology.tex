	\chapter{Methodology \& Computational Framework}
	\label{Chapter::Methodology}
	
	This chapter presents the methodology followed to simulate creep behavior, generate a synthetic dataset, represent creep curves efficiently, develop machine learning surrogate models, and implement an active learning framework for data-efficient model improvement. The approach integrates numerical simulation with data-driven learning techniques to model complex creep behavior efficiently.
	
	\section{Overview of Workflow}
	\label{Section::Workflow}
	
	Figure~\ref{fig:workflow} illustrates the complete hybrid modeling pipeline. It includes:
	
	\begin{enumerate}
		\item Sampling and selection of simulation parameters (Latin Hypercube + log-scaling).
		\item Creep curve generation using the \texttt{Lagamine} FEM solver.
		\item Preprocessing and normalization of output strain-time data.
		\item Curve representation using dimensionality reduction techniques (PCA, Kernel PCA).
		\item Supervised regression model training (Random Forest, Gradient Boosting, etc.).
		\item Prediction of creep behavior from material and loading inputs.
		\item Iterative improvement using active learning with feasibility filtering.
	\end{enumerate}

		\caption{Workflow combining finite element simulation, curve representation, supervised learning, and active learning for creep modeling.}

	\section{Finite Element Simulation Setup}
	\label{Section::FEM}
	
	\subsection{Simulation Environment and Material Model}
	
	All simulations were performed using the nonlinear finite element solver \texttt{Lagamine}, developed at the University of Liège for nonlinear, large-deformation thermomechanical analysis \cite{morch2022creep}. It supports large-strain, time-dependent, and thermomechanical creep analysis. The underlying constitutive model is based on Morch's internal variable formulation \cite{morch2022creep} and models all three creep stages.
	
	The material simulated is \textbf{30CrMoNiV5-11}, a creep-resistant alloy steel widely used in power and aerospace applications. It is part of the materials portfolio studied in the AID4GREENEST project \cite{aid4greenest}.

	\subsection{Simulation Parameters and Design Space}
	
	
	The simulations covered a high-dimensional parameter space representative of physically relevant material and loading conditions. Sampling was done using \textbf{Latin Hypercube Sampling (LHS)} to ensure uniform coverage of the design space. 
	
	However, in accordance with \textit{Morand et al.} \cite{morand2022efficient}, the hardening coefficient \( b \) was sampled on a \textbf{logarithmic scale}. This decision was based on the observation that small changes in \( b \) significantly impact the shape and slope of the creep curve, especially in the early stages. Logarithmic sampling ensured better representation of the steep regions in the creep response space and helped avoid degenerate curves with flat or purely linear behavior.
	
	The final sampled parameter space is summarized in Table~\ref{tab:param_ranges}.

	\section{Creep Curve Representation}
	\label{Section::Curve_Features}
	
	Each finite element simulation outputs a creep strain–time curve data along with the material model parameters. To enable machine learning, these curves are transformed into low-dimensional representations using a combination of mathematical fitting and data-driven feature extraction techniques. The approaches implemented in this thesis are grouped into the following categories:
	
	\subsection{A. Mathematical Models}
	
	\subsubsection{1. $\theta$-Projection Model}
	
	The $\theta$-projection model \cite{brown2002extrapolation} is a semi-empirical equation used to represent creep strain evolution with four scalar parameters:
	
	\begin{equation}
	\varepsilon(t) = \theta_1 \left(1 - e^{-\theta_2 t}\right) + \theta_3 \left(e^{\theta_4 t} - 1\right)
	\label{eq:theta_projection}
	\end{equation}
	
	Where:
	\begin{itemize}
		\item $\theta_1$ and $\theta_3$: Strain magnitudes,
		\item $\theta_2$ and $\theta_4$: Curvature (rate) parameters for primary and tertiary stages
	\end{itemize}
	
	This model is widely used for engineering creep prediction and provides a compact description of the strain evolution using physically interpretable terms. It does not explicitly capture tertiary creep behavior.
	
	\subsubsection{2. Three-Stages of Creep Model}
	
	The three-stages of creep model introduced by Dacol and Caetano~\cite{dacol2022modelling} describes the creep strain evolution using a unified analytical expression that captures all three classical stages of creep. The model is given by:
	
	\begin{equation}
	\varepsilon_e(t) = k \cdot e^{\alpha \cdot t^{\beta}}
	\label{eq:three_stage_creep_equation}
	\end{equation}
	
	where:
	\begin{itemize}
		\item \( \varepsilon_e(t) \) is the creep strain at time \( t \),
		\item \( k \) is a constant for a given temperature and load,
		\item \( \alpha \) and \( \beta \) are material-dependent fitting parameters, subject to \( \alpha > 0 \), \( \beta < 1 \), and \( \alpha \ll \beta \).
	\end{itemize}
	
	This model enables a continuous representation of the primary, secondary, and tertiary creep stages in a compact exponential-power law formulation, and is particularly suitable for long-term extrapolation of creep data.

	
	\subsection{B. Data-Driven Representations}
	
	Prior to performing dimensionality reduction, the synthetic dataset was partitioned into training and test sets, following an 80\%–20\% ratio. This allowed unbiased performance assessment of subsequent machine learning models.
	
	The creep strain–time data posed specific challenges due to variations in rupture times. In particular, early rupture curves introduced missing values or infinite entries, necessitating specialized preprocessing to ensure stable application of PCA and kernel PCA.
	
	Three strategies were implemented to handle early rupture scenarios:
	
	\begin{enumerate}
		\item \textbf{Zero padding:} Missing data points after rupture were replaced with zeros, effectively truncating the creep curve and clearly marking the rupture event.
		
		\item \textbf{Max strain padding:} After rupture, the creep strain values were held constant at the last observed strain, ensuring smooth continuity and preventing abrupt changes.
		
		\item \textbf{Normalization by rupture time:} Each creep curve was normalized based on its rupture time, converting absolute time scales to a relative scale (from 0 to 1). This approach aligns the deformation trajectories across samples, effectively mitigating variations caused by early ruptures.
	\end{enumerate}
	
	These preprocessing methods significantly improved data consistency, eliminating NaNs and infinite values, thereby enhancing the robustness of the dimensionality reduction processes.
	
	\subsubsection{1. Principal Component Analysis (PCA)}
	
	PCA is a widely used linear dimensionality reduction technique that transforms high-dimensional data into a set of orthogonal components \cite{bishop2006pattern}. The transformation preserves directions of maximum variance, allowing for compact and informative representations of creep curves. In this work, PCA was applied individually to datasets prepared with each of the three preprocessing strategies mentioned above. Typically, the first few principal components captured over 95\% of the variance, enabling substantial dimensionality reduction without significant loss of information.

		\centering
		\includegraphics[width=0.9\textwidth]{figures/pca.png}
		\caption{Principal Component Analysis(PCA) Workflow.}
		\label{fig:pca}
	\end{figure}
	
	\subsubsection{2. Kernel Principal Component Analysis (Kernel PCA)}
	
	Kernel PCA extends PCA by performing nonlinear transformations of data into a higher-dimensional feature space using kernel functions, enabling better representation of nonlinear deformation trends across creep curves. Two kernels were explored in this study:
	
	\begin{itemize}
		\item \textbf{Polynomial kernel (degree 6)}, capturing polynomially nonlinear features.
		\item \textbf{Radial Basis Function (RBF) kernel} with hyperparameter $\gamma = 0.01$, suitable for more complex, localized nonlinear patterns.
	\end{itemize}
	
	\begin{figure}[H]
		\centering
		\includegraphics[width=0.9\textwidth]{figures/kpca.png}
		\caption{Kernal Principal Component Analysis(KPCA) Workflow.}
		\label{fig:kpca}
	\end{figure}
	
	Kernel PCA proved particularly useful in distinguishing curves with non-monotonic behavior or abrupt transitions between creep stages, which linear PCA could not represent adequately.
	
	The aligned and normalized creep curves formed the final dataset used as input to the machine learning surrogate models and dimensionality reduction techniques.
		
	
	\section{Supervised Learning}
	\label{Section::Supervised_Learning}
	
	Supervised learning models were used to approximate the relationships between simulation input parameters and various output representations of creep behavior. These models serve as predictive substitutes for high-fidelity simulations, enabling both forward modeling (e.g., curve prediction) and inverse analysis (e.g., parameter identification). The core advantage lies in their ability to provide fast predictions once trained, significantly reducing computational cost compared to full-scale finite element simulations.
	
	Several regression-based algorithms were implemented using the \texttt{scikit-learn} framework \cite{pedregosa2011scikit}. These models were trained to map from the 8-dimensional input space (see Table~\ref{tab:param_ranges}) to $\theta$-projection parameters.
	
	\begin{figure}[H]
		\centering
		\includegraphics[width=0.9\textwidth]{figures/pca.png}
		\caption{Supervised Learning Models Workflow.}
		\label{fig:supervised_learning}
	\end{figure}
	
	\subsection*{1. Random Forest Regressor (RFR)}
	
	The Random Forest Regressor is an ensemble method based on decision trees, where predictions are made by averaging the output of multiple trees trained on bootstrapped samples of the dataset \cite{breiman2001random}. It naturally captures non-linear relationships and feature interactions, and is robust to outliers and overfitting. In this work, RFR was used as a baseline model due to its interpretability and fast training time.
	
	\subsection*{2. Gradient Boosting Regressor (GBR)}
	
	Gradient Boosting Regressor builds an additive model in a forward, stage-wise fashion by minimizing a specified loss function via gradient descent \cite{friedman2001greedy}. It is particularly effective for structured data with complex patterns.
	
	\subsection*{3. Stacking Regressor}
	
	Stacking, or stacked generalization, is a meta-learning technique where multiple base regressors are combined using a higher-level learner \cite{wolpert1992stacked}. In this study, base models like RFR and GBR were combined and a linear regression model was used as the meta-learner. This approach leveraged the complementary strengths of each algorithm and helped improve generalization.
	
	\subsection*{4. Voting Regressor}
	
	The Voting Regressor combines multiple base regressors by averaging their predictions (soft voting), which often improves robustness and reduces variance \cite{zhang2012ensemble}. It was found to be the most stable and consistent performer across different output types, including $\theta$ parameters and PCA components.
	
	\subsection*{Training and Validation Strategy}
	
	All models were trained on the 80\% training split of the data using 5-fold cross-validation for hyperparameter tuning. The final performance was assessed on the held-out 20\% test set. Grid search was employed for key hyperparameters such as the number of estimators, tree depth, and learning rate.
	
	These supervised regressors provided an effective solution for capturing the complex input–output relationships inherent in time-dependent, non-linear creep simulations.

	
	\section{Active Learning}
	\label{Section::Active_Learning}
	
	An active learning loop was implemented to reduce the need for dense sampling:
	
	\begin{itemize}
		\item \textbf{Feasibility filter}: An Isolation Forest model was trained to identify whether a set of input parameters would result in valid simulation output, helping avoid computationally wasted queries.
		\item \textbf{Label space}: Theta values used for diversity-based selection.
		\item \textbf{Query strategy}: Select points farthest from current label distribution.
		\item \textbf{Feedback loop}: Each batch updated the training data and retrained the model \cite{settles2010active}.
	\end{itemize}

	\section{Evaluation Metrics}
	\label{Section::Evaluation}
	
	To assess model performance comprehensively, several metrics were evaluated:
	
	\begin{itemize}
		\item \textbf{RMSE on Reconstruction}: Measures error in predicted creep curves, reflecting the ability to reconstruct the original curve shape.
		\item \textbf{Minimum Creep Rate Error}: Evaluated accuracy in capturing the slope of the secondary stage, which is critical for design applications.
		\item \textbf{Rupture Time Prediction Error}: The difference between predicted and actual rupture times, useful for lifecycle assessments.
		\item \textbf{Visual Similarity}: Overlay plots of predicted vs. true creep curves were generated to validate qualitative matching.
		\item \textbf{Inverse Accuracy}: Measured the accuracy of recovering simulation input parameters from curve features using inverse modeling.
	\end{itemize}
	
	Together, these metrics ensured both the quantitative accuracy and qualitative validity of the developed surrogate models.
