	\section{Synthetic Data Generation Setup}
	\label{Section::Synthetic_data_generation}
	
	The dataset used in this work is generated from simulations. This section explains how the dataset is generated.
	
	\subsection{Simulation Environment and Material Model}
	
	All simulations are performed using the non-linear finite element solver \texttt{LAGAMINE}, developed at the University of Liège for non-linear, large-deformation thermomechanical analysis. It supports large-strain, time-dependent, and thermomechanical creep analysis. The underlying constitutive model is based on Morch's internal variable formulation~\cite{morch2022creep} and models all three creep stages (\textit{see Section}~\ref{Subsection::Stages_of_Creep}).
	
	The AID4GREENEST project focuses on the material \textbf{30CrMoNiV5-11}, and the Morch model has adapted to reproduce the behaviour of this material~\cite{aid4greenest}. But a wide rang of material model parameters are analysed in this study, thus being independent of a material.

	\section{Creep Curve Representation}
	\label{Section::Curve_Features}
	
	Each finite element simulation outputs a creep strain–time curve data along with the material model parameters. To enable machine learning (ML), these curves are transformed into low-dimensional representations using a combination of mathematical fitting and data-driven feature extraction techniques. The synthetic dataset are partitioned into training and test sets, following an 80\%–20\% ratio. This allows unbiased performance assessment of subsequent machine learning models. The transformation is trained on creep curves from the synthetic dataset and used to project the test set into a lower-dimensional space. The inverse transformation reconstructs the approximated creep curves from the reduced representation. Figure~\ref{fig:model_flow} represents the general workflow of creep representation using different models.

	\subsection{Empirical Models}
	\label{Subsection::Empirical_Models}
	
	\subsubsection{$\theta$-Projection Model}
	\label{Subsubsection::Theta_projection_model}
	
	The $\theta$-projection model~\cite{brown2002extrapolation} is a semi-empirical formulation developed to represent the full creep strain evolution using a minimal set of parameters with physical interpretability. It is particularly suited for long-term creep life prediction and curve fitting in engineering applications.
	
	The creep strain $\varepsilon(t)$ as a function of time $t$ is modelled as:
	
	\begin{equation}
	\varepsilon(t) = \theta_1 \left(1 - e^{-\theta_2 t}\right) + \theta_3 \left(e^{\theta_4 t} - 1\right),
	\label{eq:theta_projection}
	\end{equation}
	
	where:
	\begin{itemize}
		\item $\theta_1$ [–] is the saturation strain in the primary creep stage,
		\item $\theta_2$ [1/time] governs the rate of strain accumulation during primary creep,
		\item $\theta_3$ [–] represents the amplitude of the tertiary creep contribution,
		\item $\theta_4$ [1/time] controls the acceleration of strain in the tertiary stage.
	\end{itemize}
	
	The first term in Equation~\ref{eq:theta_projection}, $\theta_1 (1 - e^{-\theta_2 t})$, represents the \textit{primary creep stage}, where the strain increases at a decreasing rate due to work hardening and microstructural recovery mechanisms. This term asymptotically approaches a plateau, consistent with the slowing creep rate typical of primary behaviour.
	
	The second term, $\theta_3 (e^{\theta_4 t} - 1)$, captures the \textit{tertiary creep stage}, characterized by accelerated strain due to damage accumulation, such as grain boundary voids, micro-cracks, or necking. The exponential form models the rapid increase in creep rate leading up to failure.
	
	The $\theta$-projection model does not explicitly model the \textit{secondary (steady-state) creep stage}, but the combination of the two exponential terms often allows it to approximate the full creep curve shape, including the near-linear region corresponding to secondary behaviour.
	
	Because of its compactness and ability to capture complex creep behaviour with only four parameters, the model is widely adopted in engineering contexts for extrapolating creep strain. But the model does not account for the rupture time and needs to be appended explicitly to the parameter vector (along with the $\theta$-parameters) if it needs to be represented. It is especially effective for high-temperature alloys in power generation and aerospace applications, where reliable long-term predictions are critical.	
	
	\subsubsection{Three Parameter Model}
	\label{Subsubsection::Three_parameter_model}
	
	The three-parameter creep model introduced by Dacol and Caetano~\cite{dacol2022modelling} describes the creep strain evolution using a unified analytical expression that captures all three classical stages of creep. The model is given by:
	
	\begin{equation}
	\varepsilon_e(t) = k \cdot e^{\alpha \cdot t^{\beta}},
	\label{eq:three_stage_creep_equation}
	\end{equation}
	
	where:
	\begin{itemize}
		\item \( \varepsilon_e(t) \) is the creep strain at time \( t \),
		\item \( k \) is a constant depending on temperature and applied stress,
		\item \( \alpha \) and \( \beta \) are material-dependent fitting parameters, subject to \( \alpha > 0 \), \( \beta < 1 \), and \( \alpha \ll \beta \).
	\end{itemize}
	
	This model enables a continuous representation of the primary, secondary, and tertiary creep stages in a compact exponential-power law formulation, and is particularly suitable for long-term extrapolation of creep data.

	
	\subsection{Data-Driven Representations}
	
	Prior to performing dimensionality reduction, the synthetic data needs some preprocessing. Each creep curve is represented as a fixed-length vector. Since individual simulations yield time series of varying lengths due to differing rupture times, all curves are preprocessed to obtain consistent dimensionality. This is done by interpolating the creep strain-time curves at a fixed number of equally spaced strain values along the horizontal axis (e.g., normalized strain or time), resulting in uniform feature vectors. This allows the dataset to be represented as a matrix $\mathbf{X} \in \mathbb{R}^{n \times p}$, where each row corresponds to a single interpolated creep curve with $p$ features.
	
	Three strategies are implemented to handle different input vector lengths:
	
	\begin{enumerate}
		\item \textbf{Zero padding:} The input vectors are filled with zeroes after the point of rupture, effectively truncating the creep curve and clearly marking the rupture event.
		
		\item \textbf{Max strain padding:} After rupture, the input vector is filled with the maximum value of creep strain (typically the creep strain at rupture), ensuring continuity and preventing abrupt changes.
		
		\item \textbf{Normalization by rupture time:} Each creep curve is normalized based on its rupture time, converting absolute time scales to a relative scale (from 0 to 1). This approach aligns the deformation trajectories across samples, effectively mitigating variations caused by early ruptures. For back-transformation, the time at rupture needs to be appended to the input vector.
		
	\end{enumerate}
	
	These preprocessing methods will significantly improve data consistency, preventing input vectors having different lengths, thereby enhancing the robustness of dimensionality reduction processes. 
	
	\subsubsection{Principal Component Analysis (PCA)}
	
	PCA is a widely used linear dimensionality reduction technique that transforms high-dimensional data into a set of orthogonal components \cite{bishop2006pattern}. It transforms high dimensional data in a lower dimensional feature space that is defined by the principal components of the data. The transformation preserves directions of maximum variance, allowing for compact and informative representations of creep curves.		
	
	Given a centred data matrix $\mathbf{X} \in \mathbb{R}^{n \times p}$ with $n$ samples and $p$ features (in this case, discretized creep strain values), the PCA transformation is obtained by solving the eigenvalue decomposition of the covariance matrix~\cite{jolliffe2002principal}:
	
	\begin{equation}
		\mathbf{C} = \frac{1}{n} \mathbf{X}^\top \mathbf{X},
	\end{equation}
	
	\begin{equation}
		\mathbf{C} \mathbf{V} = \mathbf{V} \boldsymbol{\Lambda},
	\end{equation}
	
	where:
	\begin{itemize}
		\item $\mathbf{C}$ is the $p \times p$ covariance matrix of the data,
		\item $\mathbf{V}$ is the matrix of eigenvectors (principal directions),
		\item $\boldsymbol{\Lambda}$ is the diagonal matrix of eigenvalues, representing the variance captured by each principal component.
	\end{itemize}
	
	The transformed (reduced) data matrix $\mathbf{Z} \in \mathbb{R}^{n \times k}$, where $k < p$, is obtained by projecting the original data onto the top $k$ eigenvectors:
	
	\begin{equation}
		\mathbf{Z} = \mathbf{X} \mathbf{V}_k,
	\end{equation}
	
	where $\mathbf{V}_k$ contains the first $k$ columns of $\mathbf{V}$, corresponding to the $k$ largest eigenvalues.
	
	To reconstruct the original data from the reduced representation:
	
	\begin{equation}
		\hat{\mathbf{X}} = \mathbf{Z} \mathbf{V}_k^\top.
	\end{equation}	
	
	To find a good number of principal components, an analysis can be made by plotting the cumulative explained variance vs. components to see how many principal components are able to capture over 95\% of the variance.
	

	\subsubsection{Kernel Principal Component Analysis (Kernel PCA)}
	
	Kernel PCA extends PCA by first mapping the input data $\mathbf{x}_i \in \mathbb{R}^p$ into a higher-dimensional feature space $\mathcal{F}$ via a non-linear mapping $\phi: \mathbb{R}^p \rightarrow \mathcal{F}$. Instead of computing the covariance matrix directly in $\mathcal{F}$ (which may be infinite-dimensional), Kernel PCA uses the kernel trick~\cite{scholkopf1998nonlinear}.
	
	Given $n$ data points, the kernel matrix $\mathbf{K} \in \mathbb{R}^{n \times n}$ is defined as:
	
	\begin{equation}
		K_{ij} = k(\mathbf{x}_i, \mathbf{x}_j) = \langle \phi(\mathbf{x}_i), \phi(\mathbf{x}_j) \rangle,
		\label{eq:kernel_matrix}
	\end{equation}
	
	where $k(\cdot, \cdot)$ is a positive-definite kernel function.
	
	The kernel matrix is centred as:
	
	\begin{equation}
		\mathbf{K}_c = \mathbf{K} - \mathbf{1}_n \mathbf{K} - \mathbf{K} \mathbf{1}_n + \mathbf{1}_n \mathbf{K} \mathbf{1}_n,
		\label{eq:centered_kernel}
	\end{equation}
	
	where $\mathbf{1}_n$ is the $n \times n$ matrix with all entries equal to $\frac{1}{n}$.
	
	Kernel PCA then performs eigen-decomposition:
	
	\begin{equation}
		\mathbf{K}_c \mathbf{v}_i = \lambda_i \mathbf{v}_i,
		\label{eq:kpca_eigendecomposition}
	\end{equation}
	
	where $\lambda_i$ and $\mathbf{v}_i$ are the eigenvalues and eigenvectors of the centred kernel matrix.
		
	Two kernel functions have been explored in this study. They are:
	
	\subsubsubsection{Radial Basis Function (RBF) kernel:}
	
	\begin{equation}
		k(\mathbf{x}_i, \mathbf{x}_j) = \exp\left(-\gamma \|\mathbf{x}_i - \mathbf{x}_j\|^2\right),
		\label{eq:rbf_kernel}
	\end{equation}
	
	where $\gamma$ controls the spread of the kernel. RBF kernels can approximate any continuous function on a compact domain given sufficient parameters, making them suitable for capturing arbitrary non-linear deformations in creep curves~\cite{steinwart2001influence}.
	
	\needspace{5\baselineskip}
	\subsubsubsection{Polynomial kernel:}
	
	\begin{equation}
		k(\mathbf{x}_i, \mathbf{x}_j) = (\gamma \mathbf{x}_i^\top \mathbf{x}_j + r)^d,
		\label{eq:poly_kernel}
	\end{equation}
	
	where $d$ is the degree, $\gamma$ is a scaling factor, and $r$ is the free term.
	
	Polynomial kernels are particularly suited to modelling smooth trends like the primary and tertiary creep regions observed in typical creep curves (see Figure~\ref{fig:creep_stages}). Their global nature captures general curve shapes effectively.
	
		
	\subsection{Representing creep curves using Morch model parameters}
	\label{Subsection::Morch_model_represntation}
	
	To enable fast and interpretable prediction of creep behaviour, this section focuses on representing creep curves through the parameters of the empirical $\theta$-projection model (see~\ref{Subsubsection::Theta_projection_model}). This representation serves as a compact, low-dimensional feature space that captures the essential shape characteristics of the creep curve without the need for high-dimensional, padded time series vectors. Compared to raw curve representations with data-driven models (which require padding or interpolation to handle non-uniform lengths, see Section~\ref{Subsection::Results_DataDrivenModels}), the $\theta$-model offers a fixed-size vector of four physically interpretable parameters. This makes it particularly well suited for regression tasks where consistency and interpretability are critical.
	
	Once the curves are transformed into $\theta$-parameter sets, machine learning models are trained to learn the mapping from simulation input parameters to these empirical representations. This surrogate modelling approach allows for rapid estimation of material behaviour and supports tasks such as inverse parameter identification or real-time prediction within design loops.	
	
	Supervised learning models are used to approximate the relationships between simulation input parameters and the output representations of creep behaviour. These models serve as predictive substitutes for high-fidelity simulations, enabling both forward modelling (e.g., curve prediction) and inverse analysis (e.g., parameter identification). The core advantage lies in their ability to provide fast predictions once trained, significantly reducing computational cost compared to full-scale finite element simulations.
	
	Several regression-based algorithms are implemented using the \texttt{scikit-learn} framework \cite{pedregosa2011scikit}. These models are trained to map from the eight-dimensional input space (see Table~\ref{tab:param_ranges}) to $\theta$-parameters. Figure~\ref{fig:supervised_learning} illustrates the workflow of how supervised learning is used.
	
	\begin{enumerate}
		\item The training set of creep curves obtained from the synthetic data is transformed to $\theta$-space using the $\theta$-projection model.
		\item The transformed data is used to train regression models that predicts material model parameters from the Morch model.
		\item The \texttt{LAGAMINE} solver is used to regenerate creep curves from the predicted parameters.
	\end{enumerate}

	\subsubsection*{Random Forest Regressor (RFR)}
	
	The Random Forest Regressor is an ensemble method based on decision trees. It builds a collection of $M$ decision trees $\{h_m(x)\}_{m=1}^M$ using bootstrapped samples of the training data~\cite{breiman2001random}. Predictions are obtained by averaging the output of all trees:
	
	\begin{equation}
		\hat{y}_{\text{RF}}(x) = \frac{1}{M} \sum_{m=1}^{M} h_m(x).
	\end{equation}
	
	This model naturally captures non-linear relationships and feature interactions, and is robust to outliers and overfitting. In this work, RFR is used as a baseline due to its fast training time, good generalization and the hyperparameter optimization is quite easy.
	
	\subsubsection*{Gradient Boosting Regressor (GBR)}
	
	Gradient Boosting Regressor builds an additive model sequentially. Each new tree $h_m(x)$ is trained to predict the residuals (errors) of the previous model using gradient descent~\cite{friedman2001greedy}:
	
	\begin{equation}
		\hat{y}_m(x) = \hat{y}_{m-1}(x) + \eta \cdot h_m(x),
	\end{equation}
	
	where $\eta$ is the learning rate and $h_m(x)$ is the new weak learner fitted to the negative gradient of the loss function. This method is particularly effective for structured data with complex patterns.
	
	\subsubsection*{Stacking Regressor}
	
	Stacking, or stacked generalization, is a meta-learning technique. It combines multiple base regressors $\{f_1, f_2, \dots, f_K\}$ by feeding their predictions into a higher-level learner $g$ (often a linear model)~\cite{wolpert1992stacked}:
	
	\begin{equation}
		\hat{y}_{\text{stack}}(x) = g\left(f_1(x), f_2(x), \dots, f_K(x)\right).
	\end{equation}
	
	In this study, the base models used are RFR and GBR, and a linear regressor serves as the meta-learner. This approach leverages the strengths of multiple models to improve generalization.
	
	\subsubsection*{Voting Regressor}
	
	The Voting Regressor combines multiple base models by averaging their predictions. Here again, RFR and GBR serve as the base models. For a given input $x$, the output is:
	
	\begin{equation}
		\hat{y}_{\text{vote}}(x) = \frac{1}{K} \sum_{k=1}^{K} f_k(x),
	\end{equation}
	
	where $f_k(x)$ are the individual base regressors~\cite{zhang2012ensemble}. This ensemble approach is simple yet often improves robustness and reduces variance.
	
	\subsection*{Training and Validation Strategy}
	
	All models are trained on the 80\% training split of the dataset using 5-fold cross-validation for hyperparameter tuning. Final performance is assessed on the held-out 20\% test set. Grid search is employed to find the optimal hyperparameters.
	
	\section{Active Learning}
	\label{Section::Active_Learning}
	
	Active learning is implemented for selectively querying the most informative samples in the material parameter space. This approach iteratively expands the dataset in a data-efficient manner, guided by model uncertainty and feasibility constraints.
	
	\subsection{Active Learning Workflow}
	
	The workflow is based on the method proposed by \textit{Morand et al.}~\cite{morand2022efficient}, and is illustrated in Figure~\ref{fig:active_learning}. It integrates a supervised learner, a feasibility filter, an optimizer, and a finite element oracle:
	
	\begin{itemize}
		\item \textbf{Initial Dataset ($X$, $Y$):} The starting dataset consisted of 3376 samples generated using \texttt{LAGAMINE} finite element solver. Each sample includes material model parameters ($X$) and corresponding creep response descriptors ($Y$), the $\theta$-projection features.
		
		\item \textbf{Active Learning Subset:} A subset of 100 randomly selected samples from the original dataset is used as the training pool for active learning. This subset serves as the seed data for model training and query generation.
		
		\item \textbf{Learner ($y = f(x)$):} A supervised regression model (Multi-Layer Perceptron, MLP) is trained to predict $\theta$-projection values from material input parameters.
		
		\item \textbf{Region Filter ($c = g(x)$):} An Isolation Forest is trained to distinguish valid (convergent) input samples from non-physical or divergent configurations, ensuring that queries remain within the feasible design domain.
		
		\item \textbf{Optimizer:} A Differential Evolution (DE) algorithm searches the input space for new query points $X^*$ that are both feasible and diverse in the learned $\theta$-space. Diversity is promoted to explore under-represented regions of the output space.
		
		\item \textbf{Oracle (LAGAMINE):} Each query $X^*$ is submitted to the \texttt{LAGAMINE} solver, which either returns a valid creep curve (converted into $Y^*$ via $\theta$-mapping) or failed to converge.
		
		\item \textbf{Update:} If the simulation converges, the new pair $(X^*, Y^*)$ is added to the dataset. If it fails, $X^*$ is discarded.
		
		\item \textbf{Iteration:} This loop is repeated over 100 active queries. The learner is retrained after each batch to continuously improve its predictive power.
	\end{itemize}

	\subsection{Implementation Summary}
	
	\begin{itemize}
		\item Total initial dataset: 3376 synthetic samples from \texttt{LAGAMINE} solver.
		\item Seed data for active learning: 100 random samples.
		\item Total active queries performed: 100 (1 query per iteration).
		\item Creep curves are mapped to $\theta$-space before training and querying.
		\item Differential Evolution is used for candidate search, constrained by the Isolation Forest.
		\item Convergent results are integrated into the training set; non-converging queries are excluded.
	\end{itemize}
	
	
	\section{Evaluation Metrics}
	\label{Section::Evaluation}
	
	To assess model performance comprehensively, several metrics are evaluated:
	
	\begin{itemize}
		\item \textbf{RMSE on Reconstruction}: Measures error in predicted creep curves, reflecting the ability to reconstruct the original curve shape.
		\item \textbf{Minimum Creep Rate Error}: Evaluate accuracy in capturing the slope of the secondary stage, which is critical for design applications.
		\item \textbf{Rupture Time Prediction Error}: The difference between predicted and actual rupture times, useful for lifecycle assessments.
		\item \textbf{Visual Similarity}: Overlay plots of predicted vs. true creep curves are generated to validate qualitative matching.
		\item \textbf{Inverse Accuracy}: Measure the accuracy of recovering simulation input parameters from curve features using inverse modelling.
	\end{itemize}
	
	Together, these metrics ensure both the quantitative accuracy and qualitative validity of the developed models.
