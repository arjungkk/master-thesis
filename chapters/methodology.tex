	\chapter{Methodology}
	\label{Chapter::Methodology}
	
	This chapter presents the methodology followed to simulate creep behavior, generate a synthetic dataset, represent creep curves efficiently, develop machine learning surrogate models, and implement an active learning framework for data-efficient model improvement. The approach integrates numerical simulation with data-driven learning techniques to model complex creep behavior efficiently.
	
	\section{Overview of Workflow}
	\label{Section::Workflow}
	
	Figure~\ref{fig:workflow} illustrates the complete hybrid modeling pipeline. It includes:
	
	\begin{enumerate}
		\item Generation of synthetic creep curves using the Lagamine finite element solver.
		\item Dimensionality reduction using techniques like PCA, kernel PCA.
		\item Surrogate model training using ensemble regressors.
		\item Iterative data enrichment using active learning with feasibility filtering.
	\end{enumerate}

	\section{Finite Element Simulation Setup}
	\label{Section::FEM}
	
	\subsection{Simulation Environment and Material Model}
	
	All simulations were performed using the nonlinear finite element solver \texttt{Lagamine}, developed at the University of Liège for nonlinear, large-deformation thermomechanical analysis \cite{morch2022creep}. It supports large-strain, time-dependent, and thermomechanical creep analysis. The underlying constitutive model is based on Morch's internal variable formulation \cite{morch2022creep} and models all three creep stages.
	
	The material simulated is \textbf{30CrMoNiV5-11}, a creep-resistant alloy steel widely used in power and aerospace applications. It is part of the materials portfolio studied in the AID4GREENEST project \cite{aid4greenest}.

	\subsection{Geometry and Boundary Conditions}
	
	The simulated test geometry replicates a uniaxial tensile creep experiment. Symmetry conditions were used to reduce computational cost. Constant stress was applied at the specimen top, with fixed constraints at the bottom. Time integration spanned up to 30 years using adaptive time stepping.
	
	\section{Simulation Parameters and Design Space}
	\label{Section::Design_Space}
	
	The simulations covered a high-dimensional parameter space representative of physically relevant material and loading conditions. Sampling was done using \textbf{Latin Hypercube Sampling (LHS)} to ensure uniform coverage of the design space. 
	
	However, in accordance with \textit{Morand et al.} \cite{morand2022efficient}, the hardening coefficient \( b \) was sampled on a \textbf{logarithmic scale}. This decision was based on the observation that small changes in \( b \) significantly impact the shape and slope of the creep curve, especially in the early stages. Logarithmic sampling ensured better representation of the steep regions in the creep response space and helped avoid degenerate curves with flat or purely linear behavior.
	
	The final sampled parameter space is summarized in Table~\ref{tab:param_ranges}.

	A total of 3376 simulations were generated. Each simulation produced a full creep strain vs. time curve and was used for surrogate model training or active learning evaluation.	
	
	\section{Creep Curve Representation}
	\label{Section::Curve_Features}
	
	Each finite element simulation outputs a creep strain–time curve sampled at 100 logarithmically spaced time points. To enable machine learning, these curves are transformed into low-dimensional representations using a combination of mathematical fitting and data-driven feature extraction techniques. The approaches implemented in this thesis are grouped into the following categories:
	
	\subsection{A. Mathematical Models}
	
	\subsubsection{1. $\theta$-Projection Model}
	
	The $\theta$-projection model \cite{brown2002extrapolation} is a semi-empirical equation used to represent creep strain evolution with four scalar parameters:
	
	\[
	\varepsilon(t) = \theta_1 \left(1 - e^{-\theta_2 t}\right) + \theta_3 \left(e^{\theta_4 t} - 1\right)
	\]
	
	Where:
	\begin{itemize}
		\item $\theta_1$ and $\theta_3$: Strain magnitudes,
		\item $\theta_2$ and $\theta_4$: Curvature (rate) parameters for primary and tertiary stages
	\end{itemize}
	
	This model is widely used for engineering creep prediction and provides a compact description of the strain evolution using physically interpretable terms. It does not explicitly capture tertiary creep behavior.
	
	\subsubsection{2. Three-Stage Creep Model}
	
	The three-stage model, introduced by \textit{Wessel et al.} \cite{wessel2004modelling}, is designed to model the complete creep lifecycle by decomposing the total strain into three components:
	
	\[
	\varepsilon(t) = \varepsilon_1(t) + \varepsilon_2(t) + \varepsilon_3(t)
	\]
	
	Where:
	\begin{itemize}
		\item $\varepsilon_1(t)$ models primary creep, typically using a logarithmic or saturating exponential function.
		\item $\varepsilon_2(t)$ represents secondary creep with a constant strain rate over time.
		\item $\varepsilon_3(t)$ accounts for tertiary creep, commonly represented using a damage-based or exponential growth function.
	\end{itemize}
	
	This model allows fitting of curves that exhibit all three classical creep stages and provides stage-wise decomposition of the strain history.
	
	\subsection{B. Data-Driven Representations}
	
	\subsubsection{1. Principal Component Analysis (PCA)}
	
	PCA is a widely used linear dimensionality reduction technique that transforms high-dimensional data into a set of orthogonal components \cite{bishop2006pattern}. The transformation preserves directions of maximum variance, allowing for compact and informative representations of creep curves. In this work, PCA was applied to strain-time series interpolated at 100 logarithmically spaced time points. The first few principal components typically captured over 95\% of the total variance, enabling significant reduction in feature dimensionality without major loss of information.
	
	\subsubsection{2. Kernel Principal Component Analysis (Kernel PCA)}
	
	Kernel PCA generalizes PCA to non-linear transformations by mapping the data into a higher-dimensional feature space using kernel functions. Two types of kernels were used:
	\begin{itemize}
		\item Polynomial kernel (degree 6)
		\item Radial Basis Function (RBF) kernel with $\gamma = 0.01$
	\end{itemize}
	
	Kernel PCA enables better representation of curves with non-linear deformation trends across time. It was particularly useful for distinguishing non-monotonic curve shapes or abrupt transitions in the creep stages.
	
	\subsection{C. Interpolation and Alignment Strategy}
	
	To ensure compatibility across all models, all curves were sampled at fixed logarithmic time intervals. Incomplete curves (e.g., early rupture) were aligned using two strategies:
	\begin{itemize}
		\item \textbf{Zero padding:} Remaining time points filled with zero strain.
		\item \textbf{Max-hold padding:} Remaining values held constant at the final valid strain.
	\end{itemize}
	
	These aligned, equal-length vectors were then used as targets or inputs to the machine learning models depending on the learning task.
	
	
	\section{Surrogate Modeling}
	\label{Section::Surrogate_Model}
	
	Surrogate models act as fast, predictive approximations of the high-fidelity FEM simulations. They enable rapid inference and inverse modeling of creep behavior. The following regressors \cite{bishop2006pattern} were trained:
	
	\begin{itemize}
		\item \textbf{Random Forest Regressor (RFR)}: An ensemble of decision trees that outputs the average prediction. It handles non-linearities and interactions without needing feature scaling.
		\item \textbf{Gradient Boosting Regressor (GBR)}: Builds an additive model in a forward stage-wise fashion, minimizing error via gradient descent. GBR offered higher precision but required tuning to avoid overfitting.
		\item \textbf{Stacking Regressor}: Combines predictions of multiple base regressors (e.g., RFR, GBR) using a meta-model, allowing diverse model benefits to be aggregated.
		\item \textbf{Voting Regressor}: Uses a weighted average of predictions from base learners. It showed robust and consistent performance across targets like PCA features and $\theta$-projection parameters.
	\end{itemize}

	The models were trained using the scikit-learn framework. Hyperparameters were selected using grid search with 5-fold cross-validation.	Each model mapped the 8 input parameters to $\theta$-values. Time-to-rupture and minimum creep rate were predicted as scalar outputs.
	
	\section{Active Learning}
	\label{Section::Active_Learning}
	
	An active learning loop was implemented to reduce the need for dense sampling:
	
	\begin{itemize}
		\item \textbf{Feasibility filter}: An Isolation Forest model was trained to identify whether a set of input parameters would result in valid simulation output, helping avoid computationally wasted queries.
		\item \textbf{Label space}: Theta values used for diversity-based selection.
		\item \textbf{Query strategy}: Select points farthest from current label distribution.
		\item \textbf{Feedback loop}: Each batch updated the training data and retrained the model.
	\end{itemize}
	
	\section{Evaluation Metrics}
	\label{Section::Evaluation}
	
	To assess model performance comprehensively, several metrics were evaluated:
	
	\begin{itemize}
		\item \textbf{RMSE on Reconstruction}: Measures error in predicted creep curves, reflecting the ability to reconstruct the original curve shape.
		\item \textbf{Minimum Creep Rate Error}: Evaluated accuracy in capturing the slope of the secondary stage, which is critical for design applications.
		\item \textbf{Rupture Time Prediction Error}: The difference between predicted and actual rupture times, useful for lifecycle assessments.
		\item \textbf{Visual Similarity}: Overlay plots of predicted vs. true creep curves were generated to validate qualitative matching.
		\item \textbf{Inverse Accuracy}: Measured the accuracy of recovering simulation input parameters from curve features using inverse modeling.
	\end{itemize}
	
	These metrics collectively ensured both predictive accuracy and physical relevance of the surrogate models.
