\chapter{Summary and Outlook}
\label{Chapter::Summary_Outlook}

\section{Summary}

This thesis presented a hybrid computational framework for modeling the creep behavior of metallic materials, specifically using the alloy 30CrMoNiV5-11 as a case study. The approach combined physics-based finite element simulations, empirical curve fitting, dimensionality reduction, machine learning regressors, and an active learning loop to efficiently model and predict long-term creep deformation.

The major contributions are summarized below:

\begin{itemize}
	\item \textbf{Synthetic Data Generation:} A large-scale simulation campaign (3376 simulations) was conducted using the Lagamine solver with a Latin Hypercube Sampling strategy. This provided diverse creep response data over a wide parameter space.
	
	\item \textbf{Empirical Curve Representation:} Two commonly used empirical models—the $\theta$-projection model and a three-parameter exponential creep model—were fitted to simulation data. The $\theta$-projection model showed superior reconstruction accuracy.
	
	\item \textbf{Dimensionality Reduction:} Both linear (PCA) and nonlinear (Kernel PCA) techniques were applied with various preprocessing schemes. PCA with normalization by rupture time proved particularly efficient for low-dimensional representation of creep curves.
	
	\item \textbf{Surrogate Modeling:} Ensemble regression models were trained to predict material model parameters from curve features. The Voting Regressor achieved the best performance among all models in predicting the inverse mapping from creep response to input parameters.
	
	\item \textbf{Active Learning Loop:} A feasibility-constrained active learning strategy using differential evolution was implemented to enhance data efficiency. 2000 new candidate samples were queried, of which 980 yielded convergent results and improved the model's generalization.
\end{itemize}

\section{Outlook and Future Work}

While this thesis has made substantial progress in developing a robust, data-efficient framework for creep modeling, several directions remain for further investigation and improvement.

\subsection*{1. Broader Material and Environmental Scope}

The current study focuses on a single alloy and loading type (uniaxial tension). Extending the framework to cover:

\begin{itemize}
	\item Different material systems (e.g., Ni-based superalloys, stainless steels),
	\item Multiaxial or thermomechanical loading conditions,
	\item Variable temperature profiles and environmental factors (oxidation, irradiation),
\end{itemize}

would significantly increase applicability to real-world engineering problems.

\subsection*{2. Incorporating Experimental Data}

While synthetic data enables control and scalability, integration of experimental creep data would:

\begin{itemize}
	\item Validate the surrogate models,
	\item Bridge the gap between simulated and real-world behavior,
	\item Help correct model bias or simulation errors.
\end{itemize}

Such a mixed data regime would also help benchmark the effectiveness of active learning in experimental design.

\subsection*{3. Model Uncertainty Quantification}

The current framework offers point estimates for predicted outputs. Future work can incorporate:

\begin{itemize}
	\item Bayesian regression models (e.g., Gaussian Processes),
	\item Monte Carlo dropout or quantile regression,
	\item Confidence bounds for creep curve predictions.
\end{itemize}

This will enable risk-informed decision making and model interpretability in engineering design.

\subsection*{4. Improved Convergence Classification}

Only 980 out of 2000 active learning queries converged. A better-trained feasibility classifier (e.g., using deep ensembles or hybrid physics-based indicators) could improve this acceptance rate, reducing computational waste and enhancing learning efficiency.

\subsection*{5. Integration with Design Optimization}

The surrogate models could be embedded into:

\begin{itemize}
	\item Component lifetime prediction workflows,
	\item Multiphysics optimization pipelines,
	\item Structural integrity codes for high-temperature design.
\end{itemize}

This would allow engineers to run fast forward or inverse predictions as part of a larger digital twin ecosystem.

\section{Concluding Remarks}

This thesis demonstrates the feasibility and effectiveness of combining finite element simulations, machine learning, and active sampling to model complex time-dependent material behavior. The proposed methods significantly reduce computational burden while maintaining predictive accuracy. As computational materials engineering continues to evolve, such hybrid modeling frameworks will be instrumental in developing data-efficient, physically informed, and application-ready material models for industry and research.
