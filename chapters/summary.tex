\chapter{Summary and Outlook}
\label{Chapter::Summary_Outlook}

\section{Summary}

This thesis presents a study of applying models for creep curve representations and dataset generation to efficiently model creep behaviour in metallic materials. The approach integrated high-fidelity finite element simulations, empirical curve modelling, dimensionality reduction, supervised learning, and active learning.

Key contributions include:

\begin{itemize}
	\item \textbf{Synthetic Data Generation:} 3376 simulations were performed with the Lagamine solver across a wide parameter space, capturing creep responses under varied conditions.
	
	\item \textbf{Empirical modelling:} Creep curves were fitted using the $\theta$-projection and three-parameter exponential models. The $\theta$-model consistently showed better accuracy in reconstructing simulation outputs.
	
	\item \textbf{Dimensionality Reduction:} PCA and Kernel PCA were applied with different padding strategies. Normalization by rupture time enabled effective compression into low-dimensional spaces, particularly benefiting PCA.
	
	\item \textbf{Regression modelling:} Ensemble regressors predicted material parameters from creep curve features. Among these, the Voting Regressor achieved the best trade-off between accuracy and generalization.
	
	\item \textbf{Active Learning:} A feasibility-guided loop using differential evolution added 980 new convergent samples from 2000 queries, enhancing model diversity and coverage.
\end{itemize}

\section{Future Work and Outlook}

Despite promising results, several limitations and opportunities for further work remain:

\begin{itemize}
	\item \textbf{Material and Load Diversity:} Extending the framework to other alloys and complex loading conditions (e.g., multiaxial, thermal cycling) would enhance applicability.
	
	\item \textbf{Experimental Validation:} Incorporating real creep test data would help benchmark and calibrate the models, improving reliability.
	
	\item \textbf{Uncertainty Quantification:} Future models should include confidence bounds on predictions, e.g., via Gaussian processes or Bayesian ensembles.
	
	\item \textbf{Convergence Prediction:} Improving the Isolation Forest or replacing it with more robust classifiers could reduce failed simulations in active learning.
	
	\item \textbf{Integration Potential:} The trained models can be embedded in digital twin workflows or used for rapid design iteration in high-temperature applications.
\end{itemize}

\section{Concluding Remarks}

This work demonstrates that coupling physics-based simulation with data-driven learning enables efficient, scalable, and interpretable creep modelling. The hybrid framework reduces computational overhead and opens pathways for more informed materials design. With further validation and extension, it offers strong potential for real-world integration in engineering practice.
